Conceptos Básicos

  • Dominio:

    En HTML, el término "dominio" se refiere al nombre de dominio de un sitio web, que es la dirección que se usa para acceder a él en la web.

  • Sub dominio:

    Un subdominio es una nueva dirección o URL que reemplaza el "www" de tu dominio por la palabra que desees.

  • URL:

    En HTML, una URL (Uniform Resource Locator) es una dirección que identifica un recurso único en la web, como una página web, una imagen o un archivo.

  • DNS:

    El DNS, o sistema de nombres de dominio, traduce los nombres de dominios aptos para lectura humana.

  • Hosting:

    Es el servicio que permite que una página web, escrita en HTML y otros lenguajes de programación, esté disponible en Internet para que los usuarios puedan acceder a ella.

  • FTP:

    Es un protocolo de red estándar utilizado para la transferencia de archivos de un host a otro a través de una red basada en TCP, como Internet.

  • HTTP:

    Es un protocolo de red que permite la transmisión de documentos hipertexto, como HTML, entre un cliente (por ejemplo, un navegador web) y un servidor web.

  • HTTPS:

    Es la versión segura de HTTP, el protocolo principal que se utiliza para enviar datos entre un navegador web y un sitio web. HTTPS cifra la comunicación, asegurando que los datos no sean interceptados ni manipulados por terceros.

  • W3C:

    El Consorcio WWW, en inglés: World Wide Web Consortium, es un consorcio internacional que genera recomendaciones y estándares que aseguran el crecimiento de la World Wide Web a largo plazO.

  • UTF:

    es un conjunto de estándares de codificación de caracteres que permiten representar cualquier carácter Unicode en un formato de texto

  • HTMLS:

    • es el lenguaje de marcado estándar para crear páginas web
